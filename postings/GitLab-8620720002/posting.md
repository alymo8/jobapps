## Overview

This role involves building foundational systems for GitLab's agentic AI experiences. You'll work on the platform enabling AI agents to function across the entire software delivery lifecycle, including agent creation, sharing, tool connectivity, execution, and observability across GitLab's ecosystem.

---

## Key Responsibilities

- Develop, ship, and maintain features for the Duo Agent Platform using Ruby (GitLab monolith) and Python (AI Gateway)
- Collaborate with Product, UX, frontend, backend, and AI specialists in iterative cycles
- Design and implement GraphQL and REST APIs with reliable, scalable contracts
- Strengthen automated testing using RSpec and other frameworks
- Share engineering standards and patterns focused on responsible AI integration
- Participate in Tier 2 on-call rotations for production troubleshooting
- Monitor competitive landscape for agent platform advancements

---

## Required Qualifications

- Production Ruby on Rails experience (background jobs, APIs, data models)
- Comfort across mature codebases; Python and Vue familiarity preferred
- REST/GraphQL API design expertise with attention to scalability
- Demonstrated enthusiasm for AI with hands-on tool usage
- SQL proficiency and PostgreSQL experience
- Performance optimization experience
- Strong technical communication in remote, asynchronous environments
- Openness to continuous learning
