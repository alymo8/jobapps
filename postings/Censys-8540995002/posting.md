# Senior AI/LLM Engineer

**Company:** Censys  
**Title:** Senior AI/LLM Engineer  
**Location:** Remote (US/Canada)  
**Salary:** High-cost areas (SF/NYC/Seattle): $179K–$201K USD; Other locations: $148K–$192K USD

## Job Description

The role involves developing AI-powered features to enhance search, improve recommendations, and automate workflows. This includes fine-tuning LLMs over internet-scale data, building analytics systems, and collaborating across teams to integrate seamless AI experiences.

### Key Responsibilities
- Developing AI-powered features to enhance search, improve recommendations, and automate workflows
- Fine-tuning LLMs over internet-scale data
- Building analytics systems
- Collaborating across teams to integrate seamless AI experiences

### Required Qualifications

**Experience:**
- 5+ years software engineering; 2+ years building AI-powered user-facing features
- Strong Python proficiency for backend/API development
- Familiarity with RAG evaluation frameworks like RAGAS, LangSmith and LLM regression testing

**Core Skills:**
- Rapid prototyping and validation in fast-paced, experiment-driven environments
- Prompt engineering to enhance LLM accuracy and consistency
- Secure AI implementation with guardrails and safety checks
- CI/CD pipelines and deployment best practices for AI applications

### Preferred Qualifications
- Advanced ML/AI architecture knowledge and applied deep learning
- Retrieval-augmented generation, vector search, and LLM fine-tuning experience
- Embedding models and AI-driven analytics expertise
- Experience optimizing models for low-latency, real-time interactions
- Background deploying secure systems in cybersecurity domains
