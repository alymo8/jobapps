## Job Description

### Key Responsibilities

The role focuses on building full-stack AI applications from concept to production. Core duties include:

- Developing user interfaces in React/TypeScript and backend services in Python or Node
- Implementing agentic systems with orchestration, tool calling, and memory management
- Constructing RAG pipelines including embeddings and vector search
- Ensuring production-grade quality through evaluation suites and monitoring
- Working directly with clients on AI solutions
- Mentoring junior engineers

### Required Qualifications

- 3–5 years software or data engineering experience with substantial LLM work in the past year
- Proficiency in Python and TypeScript/JavaScript
- React frontend and backend framework experience
- Expertise with RAG, embeddings, and agentic frameworks
- Specialization in one major AI platform: "Google (Gemini), Anthropic (Claude), or OpenAI"
- Cloud platform experience (GCP, Azure, AWS)
- Bachelor's or Master's degree in computer science or equivalent

### Preferred Qualifications

- MCP server experience
- Multi-agent patterns knowledge
- LLM evaluation tools familiarity
- Terraform or CI/CD pipeline expertise
- AI platform or cloud certification (required within 2 months of hire)
