## An Overview of This Role

This position focuses on building the shared foundation for GitLab Duo client applications. The team is extracting logic from the existing Language Server into a standalone TypeScript SDK—a set of well-versioned TypeScript packages that editor extensions, our web-based Duo Chat on GitLab.com, and eventually external applications can use.

As an engineer on this team, you'll:

- Work primarily with TypeScript across both frontend and backend systems
- Design and maintain the SDK's core architecture and public APIs
- Build isomorphic packages that isolate platform-specific behavior
- Develop Vue 3 components for Duo Chat on the web
- Strengthen credential handling and optimize bundle size for browser consumers
- Partner with senior and staff engineers on design and technical growth

## What You'll Do

- Develop secure, well-tested, and performant TypeScript features and improvements
- Ship small features with minimal guidance while contributing thoughtfully to code reviews
- Extract and publish TypeScript packages from the Language Server repository
- Design public APIs with clear interfaces, semantic versioning, and deprecation paths
- Build isomorphic core packages that properly isolate platform-specific behavior
- Develop Vue 3 components for Duo Chat's web interface
- Strengthen credential handling across different hosts (bearer tokens, session cookies, CSRF protection)
- Optimize bundle size and startup performance for browser-based consumers
- Support Tier 2 on-call rotation (asynchronous, primarily Slack-based)

## Required Qualifications

- Strong TypeScript proficiency across both frontend and backend contexts, including Node.js services
- Experience with build tools, monorepos, ESM modules, and dependency management
- Vue 3 and Composition API experience (or comparable modern frontend framework knowledge)
- API design experience with the ability to articulate and discuss design trade-offs
- Understanding of the differences between Node.js and browser code execution environments
- Security-minded development approach
- Strong technical communication and self-motivation in an asynchronous, distributed environment
- 3+ years of professional software engineering experience
