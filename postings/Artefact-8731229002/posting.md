## Full Job Posting

Artefact seeks an AI engineer embedded with clients to move "AI products from idea to production." The role focuses on Google's enterprise AI ecosystem with end-to-end ownership spanning interfaces, services, and infrastructure.

### Key Responsibilities

**Full-Stack Development**
- Build conversational applications and multi-step agents using TypeScript/React frontends and Python/Node backends
- Implement RAG pipelines including "ingestion, chunking, embeddings, vector and hybrid search"
- Connect systems to enterprise data via APIs and protocols like MCP

**Google AI Specialization**
- Design agents using Gemini models, Vertex AI, and Agent Development Kit
- Configure Gemini Enterprise components including Agent Designer and Agent Engine
- Build grounded applications with "Vertex AI Search and RAG Engine"

**Production Quality**
- Write evaluation suites and regression tests for LLM features
- Deploy using containers, serverless architecture, and infrastructure-as-code
- Maintain data pipelines across warehouses and vector stores

**Client Engagement**
- Work directly with clients from project start
- Use agentic coding tools daily with sound judgment
- Support pre-sales activities and mentor junior engineers

### Requirements

**Experience:**
- 3–5 years software or data engineering with "extensive hands-on use of AI tools and LLM-based development over the past year"
- Demonstrated proficiency: Python, TypeScript/JavaScript, React, backend frameworks
- Production GCP experience with Google AI stack tools
- RAG, embeddings, vector search expertise
- Data pipeline development background
- Bachelor's/Master's in computer science or equivalent

**Certifications:**
- Google Cloud certification required within first two months
- Professional Machine Learning Engineer certification preferred
- Generative AI Leader credential valued

**Preferred Skills:**
- MCP servers, multi-agent patterns, LLM evaluation tools
- Terraform, CI/CD pipelines
