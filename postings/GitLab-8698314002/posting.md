# Backend Engineer, AI Engineering: Duo Chat

**Company:** GitLab  
**Title:** Backend Engineer, AI Engineering: Duo Chat  
**Location:** Remote, Canada; Remote, United States  
**Salary:** $115,200–$194,400 USD (US residents only)

## Job Description

The role involves building the conversational AI engine behind GitLab Duo Chat, primarily using Python. You'll be working within AI Engineering, operating asynchronously across time zones to expand generative AI capabilities and strengthen testing foundations for AI features at scale.

### Key Responsibilities
- Creating secure, tested features for the chat platform
- Implementing agentic workflows using LangGraph and the Flow Registry
- Integrating chat capabilities with GitLab's Rails monolith and GraphQL API
- Writing maintainable, production-quality code with comprehensive tests
- Reviewing community contributions and identifying technical debt
- Participating in on-call support rotations (Tier 2/3)

### Required Qualifications
- Professional Python experience building production services
- Working knowledge of Ruby on Rails or willingness to learn it
- Familiarity with large language models, prompting, and function calling
- API design and performance optimization experience
- Security-focused development practices
- Strong async communication skills for remote work
- Independent work management and prioritization abilities

### Preferred Qualifications
- Experience with LangGraph, LangChain, or similar agent frameworks
- GraphQL and RSpec expertise
- Hands-on GitLab product experience
- Remote team collaboration background
- 3+ years professional software engineering experience
