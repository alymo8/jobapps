## Job Overview

Knak seeks an experienced developer to build AI agents powering their marketing automation platform. The role focuses on agent orchestration, evaluation frameworks, and production-quality implementation.

## Key Responsibilities

- **Agent Development**: Design core runtime in Python including orchestration, tool execution, and context management
- **Evaluation Systems**: Build datasets and LLM-as-judge pipelines using LangSmith
- **Quality Iteration**: Diagnose failures and optimize agent performance through benchmarking
- **Microservices**: Create Python/Node.js services for agent hosting
- **API Development**: Maintain Laravel APIs integrating agents into the platform
- **Cloud Infrastructure**: Deploy using AWS (Lambda, Bedrock, CDN)
- **Database Optimization**: Tune MySQL queries and indexing
- **Mentorship**: Lead code reviews and share agent development expertise

## Required Qualifications

- 6+ years software development experience
- Production LLM agent experience with tool calling and orchestration
- LLM evaluation design expertise (datasets, automated evaluators)
- Proficiency: Python, Node.js, MySQL
- REST APIs, TDD, CI/CD (GitHub Actions)
- SaaS, microservices, and AWS knowledge
- Docker/Kubernetes familiarity
