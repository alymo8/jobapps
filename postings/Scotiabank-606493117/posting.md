## Primary Responsibilities

The role focuses on three main areas:

**1. Agentic AI Solutions Development**
Candidates will "design, build, and productionize LLM-powered and agentic applications" including RAG systems, multi-step reasoning workflows, and prompt safety mechanisms. This includes building and consuming MCP servers with defined schemas and access boundaries.

**2. Secure Systems Architecture**
The position requires designing "testable, observable, and resilient" systems with emphasis on "secure, low-latency services" and microservices implementation. Collaboration with platform and security teams on enterprise risk and compliance standards is essential.

**3. Technical Leadership**
Responsibilities include mentoring peers, influencing engineering culture, and translating ambiguous problems into clear technical solutions.

## Required Qualifications

- Extensive Python experience with data science libraries (Scikit-learn, Pandas, NumPy)
- Hands-on LLM application development and MCP server experience
- Full-stack fundamentals and microservices expertise
- Production experience with OAuth 2.0, OpenID Connect, and SAML
- Structured/unstructured data management knowledge
- Automated testing proficiency (unit and functional testing)

## Preferred Qualifications

- Agentic AI framework experience
- MLOps principles and tools (Git, Docker, CI/CD)
- Classical machine learning algorithm expertise
- NLP and voice response application experience
- Google Vertex AI familiarity
- React and Angular web framework knowledge
