## Overview

GitLab seeks a Senior Backend Engineer for the Duo Chat team's Chat Engine. The role focuses on building core AI capabilities behind GitLab Duo Chat, a natural-language and agentic interface to GitLab's DevSecOps platform.

---

## Key Responsibilities

- Design and build flow components using Python and LangGraph within the Duo Workflow Service
- Develop backend features across Python Duo Workflow Service and GitLab Rails monolith
- Integrate generative AI models, providers, tools, and multi-agent orchestration patterns
- Design and implement GraphQL and REST APIs with chat entry points and permissions
- Improve observability and test coverage using pytest and RSpec
- Collaborate with Product, UX, frontend, and AI specialists
- Document standards and patterns for safe AI integration
- Participate in Tier 2 on-call production support rotations

---

## Required Qualifications

- Significant production Python backend experience with APIs and asynchronous workloads
- Practical experience designing AI-powered backend features with LLM integration and multi-agent orchestration
- Working proficiency in Ruby on Rails or willingness to learn it
- Ability to design REST or GraphQL APIs with scalability focus
- Strong SQL and PostgreSQL skills
- Ability to diagnose performance and reliability issues at scale
- Experience solving complex technical problems
- Openness to async-first, distributed team collaboration
