## Role Summary

This role involves building infrastructure for AI evaluation systems. The engineer will develop "distributed execution, task-set validation, graders, human-review calibration, statistical reporting" and related tools to support faster AI product decisions.

## Key Responsibilities

- Create execution engines for scoring candidate versions against task sets
- Develop task set tooling and validation systems
- Build grader infrastructure using ground truth, rubrics, and LLM approaches
- Develop calibration tooling for human reviewers
- Create leaderboards and reporting systems with statistical measures
- Support in-product feedback capture and signal extraction
- Build systems comparing offline scores with online outcomes
- Partner across product, engineering, data, and ML teams

## Required Qualifications

Candidates should have production platform/infrastructure experience, strong statistical literacy, understanding of LLM/ML evaluation, product instinct for internal tools, and collaboration skills across ambiguous problems.

## First-Year Success Metrics

Teams should stand up evaluations in days; eval results gate CI efficiently; judge-to-human agreement is monitored; launch decisions avoid statistical noise; documentation shows offline/online disagreements leading to improvements.
