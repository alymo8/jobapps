## Posting

D3 Security transforms SecOps with Morpheus, an AI-driven Autonomous Security Operations Center platform. The company automates analyst work, processes millions of alerts in real time, and aims to deliver scalable security operations solutions. The office is located in downtown Vancouver near Burrard Skytrain Station.

This is a hands-on software engineering position focused on designing, building, and managing AI agents for autonomous decision-making and complex workflows. The role bridges agentic AI engineering, full-stack development, and AI-assisted coding. Candidates will work on production problems, build reliable software, and apply LLMs to real customer use cases—not research or model training.

**Key Responsibilities:**
- Design and build AI agents with autonomous decision-making and tool use capabilities
- Implement orchestration, multi-step planning, and function calling connecting LLMs to backend services
- Create guardrails, validation, and human-in-the-loop controls for safe, auditable behavior
- Integrate agentic capabilities across product surfaces and services
- Collaborate with engineering, product, and design teams
- Improve system quality through testing, evaluation, and iteration
- Support production readiness via observability, debugging, and CI/CD
- Develop reusable components and patterns for agentic features

**Required Qualifications:**
- 2+ years of production software engineering experience
- Strong Python and/or C# skills with backend fundamentals
- Modern web development experience (JavaScript/TypeScript, React or similar)
- API-driven systems and multi-layer application experience
- Hands-on LLM or agentic application building experience
- Ability to translate ambiguous requirements into structured plans
- Understanding of agent design patterns: planning, memory, tool use, error handling
- Quality focus, code review comfort, and testing discipline
- Clear communication skills

**Nice-to-Have Qualifications:**
- Meaningful use of AI coding tools in development workflows
- Docker, Kubernetes, or Azure familiarity
- Enterprise AI product feature shipping experience
- Interest in cybersecurity, automation, or workflow systems
- LLM evaluation or reliability practice exposure
